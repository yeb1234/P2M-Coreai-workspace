# 字幕轻量清洗 light-v1

日期：2026-11-17

## 目标

把字幕转写中的纯语气词、连续重复片段、无意义填充和重复标点去掉，得到一份**派生文本**，供 LLM 总结和向量入库使用。

原始数据仍然保留：

- `videos.transcription` 不改
- `subtitle_segments.text` 不改
- VTT 和时间轴不改

因此清洗可以随时回溯，发现误删时回到原文即可。

## 清洗范围

删除：

- 独立或连续语气词：`嗯`、`啊`、`哦`、`呃`、`唉`、`诶`、`呀`、`喂`
- 连续 `哈哈`；单个 `哈` 保留，避免误删“哈工大”
- 段首/段尾单独语气词
- 相邻重复词：`这个这个`、`然后然后`、`我们我们` 等（仅总结/展示；向量不用这一条）
- 重复标点：`！！`、`？？`、`，，`
- 总结模式额外去掉结尾纯口头反问：`是吧`、`对不对`、`是不是`、`好不好`

## 向量专用安全模式

`vector_safe` 只清确定性噪声：

- 删除独立/连续语气词、连续 `哈哈`、段首段尾语气词、重复标点
- **不删除**相邻重复词（如 `这个这个`、`然后然后`）
- **不删除**结尾口头反问（如 `是吧`、`对不对`）
- 目的是避免把可能带语义的重复内容误删，保证召回和引用更保守

总结仍使用 `derived`，可以比向量清得更干净；展示字幕默认保留原文。

保留：

- 技术术语、英文标识、代码/命令
- 数字、否定词
- `首先`、`然后`、`所以`、`但是`、`如果`、`否则` 等逻辑连接词

## 已验证样例

| 原文 | 总结 `derived` | 向量 `vector_safe` |
|---|---|---|
| `Dax刚开始用啊` | `Dax刚开始用` | `Dax刚开始用` |
| `基本上都是稍微有点晕啊` | `基本上都是稍微有点晕` | `基本上都是稍微有点晕` |
| `哦哦啊啊嗯嗯` | 空 | 空 |
| `这个这个这个` | `这个` | `这个这个这个`（保留） |
| `然后然后我们我们` | `然后我们` | `然后然后我们我们`（保留） |
| `哈工大` | `哈工大` | `哈工大` |
| `还有地域模式是吧` | `还有地域模式` | `还有地域模式是吧`（保留） |
| `这个文件那个文件` | 不变 | 不变 |
| `啊这个问题` | `这个问题` | `这个问题` |

## 接入位置

- 清洗模块：`backend/app/services/subtitle_cleaner.py`
- 向量：`embedding_pipeline._build_chunks()` 在 `split_into_chunks()` 之前调用 `clean_segments(..., mode="vector_safe")`
- 总结：`ollama_summarize._summarize_compressed()` 开头调用 `clean_transcript(transcript)`（`derived` 模式）
- 清洗版本：`CLEAN_VERSION = "light-v1"`

## 已知边界

- 不调用 LLM，不做事实改写。
- 不会自动把 ASR 严重错误“修好”；只做标记，严重错误仍应人工确认或重转写。
- `filler_high` 是“被规则改动过的 segment 占比”，不是“纯语气词字占比”，用来提示口头语密度偏高，不等于必须重转写。
- 单个“哈”不删，因此“哈哈”之外的正常“哈”会保留。
