# SiteYeb 7.1 交付说明

- 日期：2026-11-20
- 版本：`7.1.0`
- 分支：`feat/7.1`
- 基线：`main` @ `e2a62e0`（`v7.0.0`）

## 版本主题

7.1 是"工作台可用性 + 轻负载"版本：先修掉长期存在的健康检查超时、侧栏拖拽失效，再把权限、转写 worker、轮询负载、学习投入上限、笔记三栏、插件栏位置、插件版本台账和浏览器标签统一收口。

## 修复项

### 后端健康检查超时

- 根因：旧 backend 容器运行态卡死，`/health` 实测 74.9 秒后连接重置；新容器本身正常，但 `DEVICE_TYPE=auto` 走到 `_resolve_device` 的 GPU-only 分支，会让 `/api/admin/health` 直接 500。
- 服务层：LLM 上下文探测改为 `ThreadPoolExecutor` 并行，整体预算 4 秒、单请求 3 秒；GPU、Redis 探测失败降级为检查项，不再炸整条路由。
- 路由层：`/api/admin/health` 改为异步，12 秒硬预算，超时也返回结构化 `ok=false + checks`。
- 前端：`fetchBackendHealth` 超时由 60 秒降到 15 秒，给后端留 3 秒余量。
- 实测：容器内带管理员令牌调用，HTTP 200 / 0.26 秒 / 17 项检查。

### 左侧栏拖拽换位

- 根因：`Sidebar` 只按 `NAV_GROUPS` 固定顺序渲染，`navOrder` 只当白名单，store 写入成功但 DOM 不变。
- 新增 `groupNavOrder`：保持"日常 → 学习 → 工具"组间顺序，组内完全按用户顺序，未知项追加不丢。
- 顶部导航同步接入 `navOrder` 与 `hiddenNavItems`。

### 管理员修改用户权限

- 用户管理"角色"列改为"权限"下拉（成员 / 管理员），变更前确认。
- 保留后端既有保护：不能降级或停用自己、至少保留一个启用管理员。

### 转写 worker 单实例

- `worker2` 增加 `profiles: ["dual-transcribe"]`，默认只启动 `worker`。
- 新增 `ops/scripts/transcribe-workers.ps1`，`-Count 1|2` 一键切换。

### 转写期网站轻负载

- 转写任务列表限制 100 条，停止拉全量后渲染数千 DOM 节点。
- 自适应轮询：有任务前台 10 秒 / 后台 30 秒；空闲前台 60 秒 / 后台 120 秒；对账 60 秒一次。
- `GET /api/ai-jobs` 增加 `reconcile=false`，轮询不再每轮做 DB/RQ 对账。
- 当前视频详情最多 30 秒刷新一次，且只在有活跃任务时刷新。

### 每日 / 每周投入上限

- 快捷档扩到 `1/2/3/4/6/8/10` 小时/天。
- 每日上限 10 小时、每周上限 70 小时，前端输入夹取，后端 Pydantic 同步限制。

## 新增能力

### 笔记工作台

- 三栏：目录 / 编辑 / 预览，目录宽度与编辑预览比例均可拖拽，双击恢复默认。
- 编辑区和预览区各自支持"占满 / 隐藏"。
- 新增独立窗口路由 `#/mdnotes-window`，不挂 Header、Sidebar、AIChatPanel。
- 排版收紧：标题 22px、行高 1.7、内边距压缩、默认 50/50 分栏、字号档位增加 13、新建默认 15。
- 持久化：`siteyeb:mdn-library-width`、`siteyeb:mdn-split-ratio`。

### 插件栏位置

- 设置 → 外观新增"左侧竖排 / 顶部横排"，桌面端与网页端都生效。
- 默认桌面端顶部、网页端左侧；移动端仍走底部导航。
- 顶部模式遵守拖拽顺序与隐藏项。

### 内部插件版本台账

- 新增 `pluginVersions.ts`，覆盖全部 30 个 `ActiveView`，记录 semver、分组、阶段、更新时间、一句话变更。
- 设置 → 插件版本（管理员）提供统计、搜索、阶段/分组筛选、复制台账 JSON。
- 定位为代码内只读台账，随代码提交，不提供运行时热插拔或回滚，避免把配置资产版本库和页面插件版本混为一谈。

### 浏览器标签标题

- 统一品牌与版本：`SiteYeb 7.1 · 灵境工作台`。
- 页面标题格式：`页面名 · SiteYeb 7.1`；笔记独立窗口为 `笔记工作台 · SiteYeb 7.1`。
- `index.html`、`package.json`、`appMeta.ts` 三处版本一致性由测试守护。
