# 2.93 技术改进报告

日期：2026-05-16

## 一、背景与动机

灵境小助手当前的模板系统完全依赖用户手动切换，用户体验割裂：
- 用户在首页说"帮我找点电商网站的视频"，模板还是上次手动选的"学习总结"。
- 没有搜索/总结/问答等场景化模板，默认的 3 个模板覆盖不了高频使用场景。
- 后期考虑引入 LangGraph 做更复杂的意图识别，但当前先用轻量正则方案快速上线。

## 二、正则意图识别模块

### 2.1 模块设计

新增 `src/lib/intentRouter.ts`，纯前端正则路由，零依赖：

```
detectIntent(input) -> IntentResult | null
detectIntentWithContext(input, pageContext) -> IntentResult | null
getTemplateIdForIntent(intent, templates) -> string | null
autoSwitchTemplate(input, pageContext, templates) -> AutoSwitchResult | null
```

### 2.2 强意图匹配（高置信度）

| 意图 | 正则模式示例 |
|------|-------------|
| 搜索 | `^搜[索找]?`, `^找[到出]?`, `帮我[找搜查]`, `关于.*的.*视频`, `\bsearch\b` 等 |
| 总结 | `总结`, `概括`, `提炼`, `归纳`, `摘要`, `复盘`, `\bsummarize\b` 等 |
| 提问 | `^问[一下]?`, `为什么`, `怎么[做弄]?`, `如何`, `什么是`, `讲讲`, `\bwhat is\b` 等 |

### 2.3 弱意图推断（低置信度，结合页面上下文）

| 页面 | 推断规则 |
|------|---------|
| 首页（无上下文） | 短输入（<20字、无标点、>1字、非问候语）→ 搜索 |
| 视频页 | 短输入（<15字、无标点）→ 总结 |
| 笔记页 | 短输入（<15字、无标点）→ 总结 |

### 2.4 模板 ID 解析

支持两层 fallback：
1. 按模板 ID 精确匹配（`video-search` → `content-summary` → `qa-question`）
2. 按名称关键词模糊匹配（`搜索` → `总结` → `问答`）

这样用户即使自定义了模板名称（如"搜索助手"），意图识别仍能正确映射。

## 三、模板扩展

`prompts/clientPrompts.ts` 默认模板从 3 个扩展到 6 个：

| ID | 名称 | 场景 |
|----|------|------|
| `video-search` | 内容搜索 | 视频库检索，优先根据检索结果回答，不强行推荐无关视频 |
| `content-summary` | 总结提炼 | 提炼重点、易错点、核心结论、可执行清单 |
| `qa-question` | 知识问答 | 直接回答，忽略不相关的视频检索结果 |
| `coding-helper` | 代码助手 | 先指出风险，再给出最小修改方案 |
| `task-planning` | 任务拆解 | 拆成今日可执行步骤，标优先级和阻塞点 |
| `general` | 通用对话 | 兜底，根据上下文灵活回答 |

## 四、AIChatPanel 集成

`src/components/layout/AIChatPanel.tsx`：

1. `sendMessage()` 发消息前调用 `autoSwitchTemplate()`
2. 若命中且模板不同 → `setActiveTemplateId()` 自动切换
3. 用 `effectiveTemplateId` 变量保证切换后的模板内容正确传入后端
4. UI 在"当前模板"名称旁显示闪烁提示：`<span class="animate-pulse">→ 已切搜索</span>`
5. `autoSwitchTimerRef` 3 秒后自动清除提示

## 七、后续建议

1. 当前是纯正则方案，后续如需更复杂意图识别（如多轮对话意图漂移），可考虑接入 LangGraph 替换 `detectIntent` 实现
2. 可考虑在 AI 设置页展示"意图识别统计"，让用户了解自动切换的触发频率和准确率
3. 用户可自定义意图关键词和映射关系，提升个性化体验
