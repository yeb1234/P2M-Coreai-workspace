# 更新日志

## 2.6.0 - 2026-05-11

这一版主要修复真实使用中的刷新状态、预览质量和持久化边界问题。

### 番茄钟

- 修复点击“重置”或“跳过”后马上刷新，旧专注倒计时又恢复的问题。
- 番茄钟运行态改为本地即时写入，不再使用 3 秒延迟写入。
- 明确临时运行态和永久数据边界：配置和完成历史保留，重置后的未完成 session 不再恢复。
- 刷新恢复 running 状态时按离线时间扣减剩余时间，paused 状态不扣减。
- 旧版本分钟制 `timeRemaining` 会迁移成秒。
- 修复保存番茄钟配置时误重算当前专注轮次的问题，背景音模式切换不再重置计时。

### 主题

- 新增 `useApplyStoredTheme`，等用户和 UI store 完成恢复后再应用主题。
- 修复刷新后皮肤可能回到默认主题的问题。

### 视频雪碧图

- 播放器进度条雪碧图预览改用共享 `useSpriteMeta`。
- 前端可显示“生成预览中”和“暂无雪碧图”状态。
- 视频主列表支持桌面端 hover 后按需加载动态缩略预览。
- 移动端禁用 hover 预览，避免误触和额外请求。
- 后端 CORS 暴露 `X-Sprite-Meta`，前端可以读取帧元数据。
- 雪碧图默认单帧从 `160x90` 提升到 `320x180`。
- 新增 `.env` 配置：`SPRITE_FRAME_WIDTH`、`SPRITE_FRAME_INTERVAL`、`SPRITE_COLUMNS`、`SPRITE_JPEG_QUALITY`。
- 旧低清雪碧图会被识别为过期，下次请求自动重建。

### 测试和文档

- 扩展番茄钟持久化测试，覆盖 reset、skip、running、paused、旧版本迁移和临时/永久数据边界。
- 新增视频卡片 hover 后才请求 sprite 的 Playwright 用例。
- 新增后端雪碧图质量 unittest。
- 更新 2.6 技术报告、README、roadmap 和踩坑记录。

## 2026-05-11

这一轮主要围绕“更像一个长期可用的个人工作台”继续打磨。

### 时间中心

- 新增时间中心插件，放在番茄钟附近，作为统一的时间控件入口。
- 接入 `react-clock` 和 `react-countdown`，模拟时钟和倒计时不再完全手写。
- 支持模拟时钟、世界时钟、正计时、倒计时、闹钟、提醒和待办提醒。
- 世界时钟支持自定义时区；默认卡片也可以按需要换成其它城市/时区。
- Header 上的实时时钟可以直接进入时间中心。

### Todo、提醒和日历

- Todo 表单支持设置具体提醒时间。
- 时间中心可以创建“待办提醒”，会同步生成待办。
- Todo 的提醒时间会同步到日历里，日历中以“提醒”事件显示。
- 日历移动端弹层也会显示提醒时间。

### 番茄钟和背景音

- 背景音播放器提升到全局层，离开番茄钟页面后不会自动停掉。
- 背景音选择、音量、手动模式和专注模式规则收敛到统一 hook。
- 番茄钟统计区、记录区和右侧间距做了细节调整。

### 视频与 AI

- 视频收藏能力开始接入 SQLite，为后续 AI 推荐保留基础数据。
- AI 任务中心和批处理逻辑继续收敛，区分继续未完成、全部重跑和真实总结状态。
- 外部 LLM 默认模型调整为 `deepseek-v4-flash`，并继续保留原 URL/API 配置方式。

### 主题与布局

- 增加并优化多套浅色/深色主题。
- 深色主题补了旧组件的浅色背景兜底。
- 多个前端页面经过 Playwright 检查，继续减少缩放、拥挤和横向溢出问题。

### 文档

- README 改成更适合开源社区阅读的中文说明。
- 明确当前项目定位：个人使用优先，适合局域网、小团体改造和二次开发。
- 补充端口说明：80 端口用于局域网访问，8000 端口用于 Vite 热更新开发。
- 补充视频转录说明：A 卡 Windows GPU 兼容层可能需要大改，CPU 路线更通用。
- 更新今天的踩坑记录，补充番茄钟配置回流规则、背景音播放边界和全局提醒弹窗。

### 性能优化

- 页面路由改为懒加载，减少首屏一次性加载所有插件页面的压力。
- Header 时钟和时间中心共用全局时钟订阅，避免多个 1 秒定时器重复运行。
- Todo 到日历的同步增加去抖，连续编辑时减少重复扫描和事件写入。
- AI 任务中心轮询降频：页面可见时 3 秒刷新，后台标签页降低到 10 秒，并避免后台刷新当前视频详情。
- 视频卡片拆成 memo 组件，减少收藏、分页和列表控制变化时的无关重渲染。
- 可见视频缩略图生成请求增加批量上限，避免一次进入大目录时把大量缺图视频全部推入生成任务。
- Todo 提醒从固定 15 秒轮询改为按最近提醒时间唤醒；没有待提醒事项时不再保留轮询。
- 视频列表的播放、收藏、分页等回调稳定化，让 memo 视频卡片能减少更多无关重渲染。
- 懒加载页面增加 hover/touch 预加载，减少第一次进入插件页面时的等待感。
- 视频导航卡片整体 memo 化，并稳定内部展示回调，减少搜索框输入、分页等操作带来的顶部导航重渲染。
- 视频搜索提交会跳过同一关键词的重复请求，清空搜索时回到普通列表。
- 文件夹搜索结果改为 memo 计算，避免输入框之外的状态变化反复递归目录树。
- 分页页码数组改为 memo 计算，减少大页数列表下的重复 UI 计算。
- 媒体查询统一收敛到 `useMediaQuery` / `useIsMobile` / `useWindowWidth`，避免组件各自监听 viewport。
- 日历页把事件过滤、待办分组、番茄热力和周/月视图派生数据迁到 `calendarDerivedData`。
- 通知面板拖拽定位迁到纯 helper，并补充边界测试，避免弹层贴边或拖出视口。
- 视频播放器进度条拖动、触摸拖动和悬停预览迁到 `useVideoProgressScrubber`。
- 视频播放器加载、错误、音量同步迁到 `useVideoElementEvents`，播放器 JSX 只保留编排。
- 视频观看进度百分比统一通过 `getWatchProgressPercent` 计算，播放列表不再用估算比例显示假进度。
- 灵境小助手页面上下文改为订阅当前页面、视频和笔记状态变化，不再 1.5 秒固定刷新。
- Todo 到日历同步拆成 `buildTodoCalendarSyncPlan`，先计算新增/更新/删除计划，再由 effect 执行写入。
- 补充多组 Vitest 和契约测试，覆盖通知定位、通知时间、视频进度、待办日历同步和性能结构边界。

## 2.5.0 正式版

- 标记当前前端和文档为 `2.5.0`。
- 这一版重点不是新增单个功能，而是把视频站、时间中心、番茄钟、主题、声音、AI 助手和跨模块同步整理到更适合长期维护的结构。
- 当前定位仍然是个人优先、局域网友好、适合小团体继续改造的本地 CoreAI 工作台。
