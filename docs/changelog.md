# 更新日志

## 2.7.0 - 2026-05-12

这一版继续围绕日常真实使用体验打磨，重点修复时区偏移、番茄钟显示逻辑、日历交互和数据库写入性能。

### Todo / 日历 / 排程

- 修复时区偏移导致的刷新后时间错乱：日期时间工具统一输出本地时间字符串（不带 `Z`），避免 UTC 转换导致的 8 小时偏移。
- TodoForm 时间输入默认整点填充：开始/截止时间输入框空值时自动填入下一个整点，结束时间自动 +1h，支持跨天（23:01 → 次日 00:00/01:00）。
- Todo 快捷输入解析的提醒时间同样使用本地时间字符串，与表单保持一致。
- 日历1和日历2进入页面时自动加载后端排程数据，避免刷新后显示空状态。
- 日历2支持拖拽事件项下边缘调整时长：按住底部 handle 上下拖动即可拉长或缩短，15 分钟对齐，松开自动保存到后端。

### 番茄钟

- 修复"本轮"显示固定为 0/4 的问题：现在按关联任务的 `pomodoroRounds` 动态显示（如 2 个番茄的任务显示 0/2）。
- `pomodoroRounds` 用户设定优先于时间区间推导；未设定时才按开始/截止时间估算。
- 番茄钟完成目标番茄数后自动勾选待办完成，重置后解除任务关联，不再显示旧专注项目名。
- 跳过阶段不算完成番茄，避免误算完成数。
- 番茄钟无真实任务时自动挂起虚拟占位任务，避免 undefined 关联问题。

### 数据库与性能

- 番茄钟高频操作引入 500ms debounce：同一 key 在 500ms 内多次写入合并为一次 HTTP PUT，大幅减少请求数。
- runtime 和 history 用 debounced 写入，config 保持 immediate（低频且用户期望即时生效）。
- 页面关闭前自动 flush pending 写入，防止数据丢失。

### 笔记

- 修复 Alt+Enter 在编辑笔记时无法换行的问题：当 Enter 行为设为"Enter 保存、Alt+Enter 换行"时，手动在光标位置插入换行符并恢复光标位置，避免浏览器默认行为不一致导致无响应。

### 后端

- 修复打开日历页面时大量 405 报错：`backend/app/main.py` 中遗漏了 `app.include_router(calendar_events.router)`，导致 `/api/calendar-events` 请求落入仅支持 GET 的 SPA catch-all 路由。

### 测试

- 全量测试覆盖 187/187 通过（Vitest）。

## 2.6.0 - 2026-05-11

这一版主要修复真实使用中的刷新状态、预览质量和持久化边界问题。

### Todo / 日历 / 排程

- Todo、日历1、日历2 统一切到后台 `schedule_items`，开始时间和截止时间都按分钟级保存。
- Todo 右侧专注按钮不再依赖手动勾选番茄数；只要任务设置了开始时间和截止时间，就会按时间段自动估算需要的番茄数。
- 日历2 修复拖动后变成两条事件、位置不准的问题，拖动更新会回写原排程项。
- 日历2 新增同时间段任务冲突显示：重叠任务按列分布展示，避免后一个任务完全盖住前一个任务。

### 番茄钟

- 修复点击“重置”或“跳过”后马上刷新，旧专注倒计时又恢复的问题。
- 番茄钟运行态保留浏览器本地每秒计时，本地缓存即时写入，不再使用 3 秒延迟写入。
- 新增后台 v2 同步层：`p2m-pomodoro-config-v2`、`p2m-pomodoro-history-v2`、`p2m-pomodoro-runtime-v2` 分别保存设置、完成历史和轻量运行快照。
- 关键事件立即写后台，运行中每 15 秒写一次小快照，页面隐藏/刷新/关闭前补写一次；不做每秒数据库写入。
- 启动时会加载后台设置、历史和运行快照，按离线经过时间推算剩余秒数；过期运行态最多恢复成 0 秒暂停，不静默增加完成历史。
- 多设备规则收敛为：运行态和设置取更新时间最新者，完成历史按 session id 合并。
- 刷新恢复 running 状态时按离线时间扣减剩余时间，paused 状态不扣减。
- 旧版本分钟制 `timeRemaining` 会迁移成秒。
- 修复保存番茄钟配置时误重算当前专注轮次的问题，背景音模式切换不再重置计时。
- Todo 覆盖重新开始番茄钟时会清理环境音选择和运行快照，避免声音已停但图标仍显示选中。
- 背景音按钮状态统一到 `ambientSound`：`none` 表示关闭，具体声音表示对应按钮亮起。
- `p2m-pomodoro-config-v2` 现在保存完整番茄参数、环境音策略、当前选中环境音、各环境音音量和上次是否正在播放，刷新或局域网另一台电脑恢复时不再只亮按钮不播放。
- 手动控制下选中背景音会立即播放，并在休息阶段持续播放；随专注计时才只在专注阶段播放。
- 随专注计时的非专注阶段选择背景音只保存为“待启动”，专注开始或专注中切换才播放，重置会把按钮复位为关闭。
- 如果浏览器拒绝自动播放，背景音会写回关闭状态，避免按钮继续亮着但实际没有声音。
- 环境音增加后台预加载和 7 天浏览器缓存，优先预热上次选择的声音，再顺序预热其它声音。

### 主题

- 新增 `useApplyStoredTheme`，等用户和 UI store 完成恢复后再应用主题。
- 修复刷新后皮肤可能回到默认主题的问题。

### 视频雪碧图

- 播放器进度条雪碧图预览改用共享 `useSpriteMeta`。
- 前端可显示“生成预览中”和“暂无雪碧图”状态。
- 视频主列表支持桌面端 hover 后按需加载动态缩略预览。
- 移动端禁用 hover 预览，避免误触和额外请求。
- 后端 CORS 暴露 `X-Sprite-Meta`，前端可以读取帧元数据。
- 雪碧图默认单帧从 `160x90` 提升到 `320x180`。
- 新增 `.env` 配置：`SPRITE_FRAME_WIDTH`、`SPRITE_FRAME_INTERVAL`、`SPRITE_COLUMNS`、`SPRITE_JPEG_QUALITY`。
- 旧低清雪碧图会被识别为过期，下次请求自动重建。

### 测试和文档

- 扩展番茄钟持久化与同步测试，覆盖 reset、skip、running、paused、旧版本迁移、关键事件远程写入、15 秒 heartbeat、远程恢复、历史按 session id 合并和旧远程历史不回流。
- 新增视频卡片 hover 后才请求 sprite 的 Playwright 用例。
- 新增后端雪碧图质量 unittest。
- 更新 2.6 技术报告、README、roadmap 和踩坑记录。
- 最新本地验证：`npm run test` 19 个测试文件、146 个测试通过；`npm run build` 通过。
- 说明：完整 Playwright 布局截图套件当前仍有既有快照差异和缺失基线，更新截图需单独确认。

## 2026-05-11

这一轮主要围绕“更像一个长期可用的个人工作台”继续打磨。

### 时间中心

- 新增时间中心插件，放在番茄钟附近，作为统一的时间控件入口。
- 接入 `react-clock` 和 `react-countdown`，模拟时钟和倒计时不再完全手写。
- 支持模拟时钟、世界时钟、正计时、倒计时、闹钟、提醒和待办提醒。
- 世界时钟支持自定义时区；默认卡片也可以按需要换成其它城市/时区。
- Header 上的实时时钟可以直接进入时间中心。

### Todo、提醒和日历

- Todo 表单支持设置具体提醒时间。
- 时间中心可以创建“待办提醒”，会同步生成待办。
- Todo 的提醒时间会同步到日历里，日历中以“提醒”事件显示。
- 日历移动端弹层也会显示提醒时间。

### 番茄钟和背景音

- 背景音播放器提升到全局层，离开番茄钟页面后不会自动停掉。
- 背景音选择、音量、手动模式和专注模式规则收敛到统一 hook。
- 番茄钟统计区、记录区和右侧间距做了细节调整。

### 视频与 AI

- 视频收藏能力开始接入 SQLite，为后续 AI 推荐保留基础数据。
- AI 任务中心和批处理逻辑继续收敛，区分继续未完成、全部重跑和真实总结状态。
- 外部 LLM 默认模型调整为 `deepseek-v4-flash`，并继续保留原 URL/API 配置方式。
- AI 设置页提示词模板支持完整管理：列出、切换、编辑名称和内容、新建、删除、重置默认。

### 主题与布局

- 增加并优化多套浅色/深色主题。
- 深色主题补了旧组件的浅色背景兜底。
- 多个前端页面经过 Playwright 检查，继续减少缩放、拥挤和横向溢出问题。

### 文档

- README 改成更适合开源社区阅读的中文说明。
- 明确当前项目定位：个人使用优先，适合局域网、小团体改造和二次开发。
- 补充端口说明：80 端口用于局域网访问，5002 端口用于 Vite 热更新开发。
- 补充视频转录说明：A 卡 Windows GPU 兼容层可能需要大改，CPU 路线更通用。
- 更新今天的踩坑记录，补充番茄钟配置回流规则、背景音播放边界和全局提醒弹窗。

### 性能优化

- 页面路由改为懒加载，减少首屏一次性加载所有插件页面的压力。
- Header 时钟和时间中心共用全局时钟订阅，避免多个 1 秒定时器重复运行。
- Todo 到日历的同步增加去抖，连续编辑时减少重复扫描和事件写入。
- AI 任务中心轮询降频：页面可见时 3 秒刷新，后台标签页降低到 10 秒，并避免后台刷新当前视频详情。
- 视频卡片拆成 memo 组件，减少收藏、分页和列表控制变化时的无关重渲染。
- 可见视频缩略图生成请求增加批量上限，避免一次进入大目录时把大量缺图视频全部推入生成任务。
- Todo 提醒从固定 15 秒轮询改为按最近提醒时间唤醒；没有待提醒事项时不再保留轮询。
- 视频列表的播放、收藏、分页等回调稳定化，让 memo 视频卡片能减少更多无关重渲染。
- 懒加载页面增加 hover/touch 预加载，减少第一次进入插件页面时的等待感。
- 视频导航卡片整体 memo 化，并稳定内部展示回调，减少搜索框输入、分页等操作带来的顶部导航重渲染。
- 视频搜索提交会跳过同一关键词的重复请求，清空搜索时回到普通列表。
- 文件夹搜索结果改为 memo 计算，避免输入框之外的状态变化反复递归目录树。
- 分页页码数组改为 memo 计算，减少大页数列表下的重复 UI 计算。
- 媒体查询统一收敛到 `useMediaQuery` / `useIsMobile` / `useWindowWidth`，避免组件各自监听 viewport。
- 日历页把事件过滤、待办分组、番茄热力和周/月视图派生数据迁到 `calendarDerivedData`。
- 通知面板拖拽定位迁到纯 helper，并补充边界测试，避免弹层贴边或拖出视口。
- 视频播放器进度条拖动、触摸拖动和悬停预览迁到 `useVideoProgressScrubber`。
- 视频播放器加载、错误、音量同步迁到 `useVideoElementEvents`，播放器 JSX 只保留编排。
- 视频观看进度百分比统一通过 `getWatchProgressPercent` 计算，播放列表不再用估算比例显示假进度。
- 灵境小助手页面上下文改为订阅当前页面、视频和笔记状态变化，不再 1.5 秒固定刷新。
- Todo 到日历同步拆成 `buildTodoCalendarSyncPlan`，先计算新增/更新/删除计划，再由 effect 执行写入。
- 补充多组 Vitest 和契约测试，覆盖通知定位、通知时间、视频进度、待办日历同步和性能结构边界。
