# 待办、提醒时间和番茄快捷输入规则

这份文档用于固定待办输入框后续要遵守的语义，避免“提醒时间”“日历同步”“番茄计划”各写各的。

## 一句话原则

- `下午4点` 表示今天下午 4 点。
- `明天上午10点` 表示明天上午 10 点。
- `后天下午3点` 表示后天下午 3 点。
- `/t1` 表示 1 个番茄，不是 1 轮番茄。

## 触发位置

规则主要作用在待办快速输入框和待办编辑标题里。

用户输入一行内容后，系统拆成四类信息：

| 信息 | 例子 | 写入字段 |
| --- | --- | --- |
| 待办标题 | `整理日报` | `title` |
| 提醒时间 | `下午4点`、`明天9点` | `reminderAt` |
| 排程时间 | 开始时间 + 截止时间 | `schedule_items.startAt` / `schedule_items.dueAt` |
| 截止日期 | `今天`、`明天`、`后天` | `dueDate` / `schedule_items.dueAt` |
| 手动番茄数 | `/t1`、`/t3` | `pomodoroRounds` |

解析完成后，快捷符本身不应该留在标题里。

例如：

```text
整理日报 下午4点 /t1
```

应该保存为：

- 标题：`整理日报`
- 提醒时间：今天 16:00
- 截止日期：今天
- 番茄计划：1 个番茄

## 时间表达规则

### 默认空值

普通新建待办时，截止日期和提醒时间默认都留空。

- 截止日期：第一次点击截止日期输入框时，才默认填入当天日期。
- 提醒时间：第一次点击提醒时间输入框时，才默认填入当前时间至少 30 分钟后的 `:00` 或 `:30`。
- 从日历某一天发起新建待办时，可以直接带入那一天作为截止日期，因为用户已经明确选过日期。

### 当天时间

只写时间、不写日期时，默认是当天。

| 输入 | 含义 |
| --- | --- |
| `下午4点` | 今天 16:00 |
| `上午9点` | 今天 09:00 |
| `中午12点` | 今天 12:00 |
| `晚上8点` | 今天 20:00 |
| `16:30` | 今天 16:30 |
| `4点半` | 今天 04:30，除非带了下午/晚上等前缀 |

后续如果要更智能，可以把“已经过去的当天时间”自动推到明天，但当前规则先保持可预测：没有日期词就是今天。

### 相对日期

| 输入 | 含义 |
| --- | --- |
| `今天` | 当天 |
| `明天` | 当前日期 + 1 天 |
| `后天` | 当前日期 + 2 天 |

和时间组合时：

| 输入 | 含义 |
| --- | --- |
| `明天下午4点` | 明天 16:00 |
| `后天上午9点半` | 后天 09:30 |
| `明天16:30` | 明天 16:30 |

### 只有日期没有时间

如果只输入 `今天`、`明天`、`后天`，只设置截止日期 `dueDate`，不强行生成提醒时间。

如果需要提醒，必须同时写出具体时间，例如 `明天下午4点`。

## 提醒和日历联动

待办现在有三类时间语义：

- `startAt`：开始时间，用于 Todo、日历1、日历2 的排程开始。
- `dueAt` / `dueDate`：截止时间或截止日期，用于 Todo、日历1、日历2 的排程结束。
- `reminderAt`：具体提醒时间，用于通知、时间中心和日历提醒事件。

联动规则：

1. 待办有开始/截止时间时，写入后台 `schedule_items`。
2. 待办有 `reminderAt` 时，日历显示提醒事件。
3. 时间中心显示来自待办的提醒。
4. 待办完成后，不再触发提醒。
5. 修改待办开始/截止时间时，日历1 和日历2 要同步更新同一条排程。
6. 删除待办或清空提醒时间时，日历里的对应提醒事件要同步删除。

## 番茄快捷符

当前优先规则：只要 Todo 设置过开始时间和截止时间，Todo 条右侧专注箭头就按这个时间段自动估算番茄数，不需要再勾选番茄钟时间。

估算规则：

- 按当前番茄设置里的 `work + shortBreak` 完整周期向下取整。
- 默认 `25 + 5` 分钟时，2 小时给 4 个番茄。
- 如果是 `35 + 5` 分钟，2 小时给 3 个番茄。
- 优先保证 focus 轮次跑完，不为了填满时间强行增加跑不完的半轮。

### `/tN`

`/tN` 表示手动指定 N 个番茄。

重点：这里是“个番茄”，不是“轮”。

| 输入 | 含义 |
| --- | --- |
| `/t1` | 1 个番茄 |
| `/t2` | 2 个番茄 |
| `/t4` | 4 个番茄 |

例如：

```text
看一节课程 /t1
```

应该保存为：

- 标题：`看一节课程`
- 番茄计划：1 个番茄

### 和现有“轮”的区别

待办编辑弹窗里的预设按钮可以显示“1 轮 = N 个番茄”，这里的“轮”跟快捷输入不是一回事。

- 编辑弹窗里的 `1 轮`：按番茄钟设置里的长休息间隔换算，例如 4 个番茄。
- 快捷输入里的 `/t1`：永远是 1 个番茄。

所以不能把 `/t1` 解析成 1 轮。

如果同一个 Todo 同时有开始/截止时间和 `/tN`，界面启动番茄钟时优先按明确时间段重新估算；`/tN` 更适合作为没有排程时间时的手动计划。

## 颜色快捷符

当前已有颜色快捷符：

| 快捷符 | 含义 |
| --- | --- |
| `/g` | 绿色 |
| `/p` | 粉色/高优先级 |
| `/y` | 黄色/中优先级 |
| `/b` | 蓝色/低优先级 |

颜色快捷符可以和时间、番茄一起使用：

```text
写周报 明天下午4点 /t2 /p
```

应该保存为：

- 标题：`写周报`
- 提醒时间：明天 16:00
- 截止日期：明天
- 番茄计划：2 个番茄
- 颜色/优先级：粉色

## 推荐实现顺序

1. 抽出统一解析函数，例如 `parseTodoQuickInput(text, now)`。
2. 快速输入框和待办编辑标题都调用同一个解析函数。
3. 为 `下午4点`、`明天`、`后天`、`/t1`、开始/截止时间自动估算番茄写单元测试。
4. 再接入 UI 文案提示，避免用户猜规则。
