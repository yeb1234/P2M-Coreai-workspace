## 1. 时区偏移修复

**根因**: `toMinuteISOString` / `toISODateTimeString` 使用 `Date.toISOString()` 输出 UTC 字符串（如 `2026-05-12T12:00:00Z`）。后端 SQLAlchemy `DateTime` 存储为 naive datetime，值为 `12:00`。前端刷新后读回 `2026-05-12T12:00:00`，当作本地时间解析 → 显示 12:00（原设定 20:00）。

**修复**:
- `src/lib/scheduleTime.ts` `toMinuteISOString`: 改为 `YYYY-MM-DDTHH:mm:ss`（本地时间，不带 `Z`）
- `src/lib/date.ts` `toISODateTimeString`: 同上
- `src/lib/todoQuickInput.ts`: `reminderAt` 从 `toISOString()` 改为 `toMinuteISOString()`
- `src/components/todo/TodoForm.tsx`: `getReminderDefaultParts` 和 `handleEndTimeFocus` 同步修复
- 日历2 "新建状态没保存"也是因为时间偏移后显示位置变了，修复时区后同步解决

## 2. TodoForm 时间输入自动填充

**新增**: `src/lib/scheduleTime.ts` `getNextWholeHour()`
- 当前分钟非0则进下一整点，整点则保持当前小时
- 返回 startTime / endTime（+1h）及 date / endDate，正确处理跨天

**TodoForm.tsx**:
- 开始时间 onFocus: 空值时联动填充 startDate + startTime + endTime + dueDate
- 结束时间 onFocus: 基于 startDate+startTime 精确计算 +1h 的跨天情况
- 日期输入框 onFocus: 空值时自动填充当天

## 3. 番茄钟显示逻辑修复

**根因**: PomodoroTimer.tsx 显示 `sessionsCompleted % longBreakInterval / longBreakInterval`（固定4），与任务实际设定番茄数无关。

**修复**:
- 新增 `plannedPomodoros`: 关联任务时优先取 `todo.pomodoroRounds`，否则 fallback 到 `getSchedulePomodoroPlan` 推算
- 新增 `completedPomodoros`: 关联任务时取 `todo.pomodoroCount`，无任务时取 `sessionsCompleted`
- 显示改为 `本轮: {completedPomodoros}/{plannedPomodoros}`
- 完成目标后 `useCrossModuleSync.ts` 通过 `calculateSchedulePomodoroRounds` 判断 `reachedTarget`，自动 `status: 'completed'`
- 重置后 `linkedTodoId` 设为 `null`，不再显示旧专注项目名

**用户设定优先**:
- `pomodoroRounds > 0` 时直接用它作为番茄钟个数，不再按时间区间推算
- TodoItem.tsx 新增 `effectiveRounds`，`doStartPomodoro` 不再覆盖用户设定

## 4. 番茄钟数据库写入性能优化

**根因**: 每个用户操作（start/pause/resume/complete/skip/reset）都立即触发 1-2 次 HTTP PUT，高频操作时请求数爆炸。

**优化**:
- `src/lib/pomodoroSync.ts` 新增 `scheduleSaveJson`: 500ms debounce，同一 key 多次写入合并为一次请求
- `savePomodoroRemoteRuntime` / `savePomodoroRemoteHistory` 改用 debounced
- `savePomodoroRemoteConfig` 保持 immediate（低频配置，用户期望即时生效）
- 新增 `flushPendingPomodoroSaves()`: 页面 `beforeunload` 时 flush，防止数据丢失

## 9. 笔记编辑 Alt+Enter 换行

**问题**:
当 
noteEnterBehavior='enter_save' 时，Alt+Enter 本应换行，但代码仅直接 return，未调用 preventDefault()，也未手动插入换行符。部分浏览器下 Alt+Enter 不会触发 textarea 的默认换行行为，导致按了完全没反应。

**修复**:
- src/components/notes/NotesPage.tsx 中 handleEditContentKeyDown 在 shouldSave=false 时：
  - preventDefault() 阻止默认行为；
  - 读取光标位置 selectionStart/selectionEnd；
  - 手动在光标处插入 `\\n`；
  - 通过 `requestAnimationFrame` 恢复光标位置到新行。

## 10. 后端日历路由 405 报错

**问题**:
打开日历页面时控制台疯狂输出 405 Method Not Allowed（POST /api/calendar-events）。

**根因**:
ackend/app/main.py 虽然导入了 calendar_events 模块，但遗漏了 pp.include_router(calendar_events.router)。所有 /api/calendar-events 请求落入最后的 SPA catch-all 路由（仅支持 GET），POST/PATCH/DELETE 均返回 405。

**修复**:
补注册路由：pp.include_router(calendar_events.router)，重启后端后生效。
