# 视频站模块设计文档

## 模块定位
整合学习资源的视频平台，专注于 IT/技术类内容。类似 B 站的播放体验，结合 AI 能力实现知识沉淀。

---

## 核心功能

### 1. 视频播放器
- 类 B 站播放器体验
- 倍速播放 (0.5x ~ 3.0x)
- 画质切换 (360p / 720p / 1080p)
- 弹幕支持（可选）
- 进度条预览缩略图
- 键盘快捷键 (空格暂停, ←→ 快进退, F 全屏)

### 2. 视频下载（可选）
- 一键缓存到本地
- 选择画质下载
- 下载队列管理
- 离线播放支持

### 3. AI 字幕转录
- 语音识别自动生成字幕
- 中英双语字幕支持
- 字幕时间轴对齐
- 字幕搜索定位
- 导出字幕文件 (SRT/VTT)

### 4. 视频总结 & 知识索引
- AI 自动总结视频内容
- 提取关键知识点
- 生成章节目录
- 构建可搜索的知识库
- 视频间知识关联

## 数据模型

```
Video
├── id: string
├── title: string
├── url: string
├── thumbnail: string
├── duration: number
├── channel: string
├── tags: string[]
├── description: string
├── transcript: TranscriptSegment[]
├── summary: string
├── chapters: Chapter[]
├── watchProgress: number
├── starred: boolean
├── downloaded: boolean
└── createdAt: datetime

TranscriptSegment
├── startTime: number
├── endTime: number
├── text: string
└── lang: 'zh' | 'en'

Chapter
├── title: string
├── startTime: number
└── summary: string
```

## 技术方案

### 视频播放
- 方案 A: iframe 嵌入第三方 (快速实现)
- 方案 B: 自研播放器 (video.js / plyr)
- 推荐: 先用 iframe，后期替换

### 字幕转录
- Whisper API / 本地 Whisper 模型
- 分段转录 + 时间轴对齐

### 视频总结
- LLM API (Claude / GPT)
- 输入: 字幕文本
- 输出: 摘要 + 章节 + 知识点

### 数据存储
- IndexedDB (Dexie) 存储视频元数据
- 字幕/总结存入本地数据库
- 支持全文搜索
