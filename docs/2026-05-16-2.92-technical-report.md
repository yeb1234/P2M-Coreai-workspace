# 2.92 技术改进报告

日期：2026-05-16

## 一、番茄钟日历规划逻辑重构

### 1.1 "轮"概念引入

之前番茄钟规划按单个 work+shortBreak 周期计算，没有纳入 longBreak。用户反馈：
- "一定要包含长休息"
- "一次 todo 最多不超过两轮番茄钟"
- "第二轮后的长休息不计入"

引入"轮"概念：
- 1 轮 = `longBreakInterval` 个番茄钟（默认 4 个 work + 3 个 shortBreak + 1 个 longBreak）
- 2 轮 = 2 × `longBreakInterval` 个番茄钟
- 用户可设置 `longBreakInterval` 为 2/3/4 等，默认 4

### 1.2 轮数封顶

```
calculatePomodoroRounds(durationMinutes, config):
  if duration < 1轮时长:
    return floor(duration / (work+shortBreak)), 封顶 longBreakInterval-1
  if duration < 2轮时长:
    return longBreakInterval
  return 2 * longBreakInterval  // 封顶
```

用户手动设置 `pomodoroRounds` 也封顶为 `2 * longBreakInterval`。

### 1.3 长休息纳入规则

| 轮数 | plannedMinutes 计算 |
|------|---------------------|
| ≤1 轮 | rounds×work + (rounds-1)×shortBreak，若 rounds==longBreakInterval 再加 longBreak |
| >1 轮 | rounds×work + (rounds-2)×shortBreak + longBreak（第2轮后的 longBreak 不计入） |

### 1.4 双向反推

TodoForm 新增"预计番茄钟数量"选择器：
- 选项：`[1, 2, 3, 4, 6, 7, 8]`（5 不在允许列表，因为 5 会跨过 1 轮进入 2 轮但不完整）
- 修改数量 → 自动修正截止时间（`dueAt = startAt + plannedMinutes`）
- 修改截止时间 → `useEffect` 自动反推数量

### 1.5 日历拖拽限制

Calendar2Page：
- `moveSelection`: todo 拖动区域 `endMinutes` 上限 `startMinutes + maxTodoMinutes`
- `handleGridDragOver` / `handleGridDrop`: lane 拖拽创建 todo 时默认时长限制为 2 轮
- resize handle `onPointerMove`: todo 类型拉伸时 `newEndMinutes` 上限 2 轮
- `saveDraft`: createTodo 时根据 `getSchedulePomodoroPlan` 自动修正 `dueAt`

### 1.6 未排期 todo

- 不显示预计时间和进度条（`effectiveRounds = 0`）
- 运行按钮对所有未完成 todo 可用
- 运行时 `calculateSchedulePomodoroRounds` 返回 `config.longBreakInterval`（1 轮）

## 二、自动主题调度优化

### 2.1 手动选主题不关闭调度

之前用户手动点主题按钮会自动关闭 `themeScheduleEnabled`，导致用户以为调度坏了。

改为：
- 手动选主题 → 立即应用，不修改调度开关
- 调度只在规则生效/结束时间点自动切换
- 规则结束后恢复到用户手动选择的主题

### 2.2 精确 setTimeout 触发

之前 `setInterval(60s)` 每分钟轮询，浪费资源。

改为：
- 启动时计算未来 7 天内所有规则的生效/结束时间点
- `setTimeout` 精确调度到最近的时间点
- 触发后重新评估并递归调度下一个
- 从每分钟检查 → 仅在规则时间点触发一次

### 2.3 规则冲突策略

明确为"后面的规则优先级更高"（类似 CSS 层叠）。用户通过调整规则顺序控制哪条胜出。

### 2.4 旧数据迁移修复

`uiStore.ts merge` 函数中 `...saved` 展开旧数据时，新字段 `themeScheduleEnabled` / `themeScheduleRules` 会变成 `undefined`。

修复：`saved.xxx ?? current.xxx` 回退到默认值。
